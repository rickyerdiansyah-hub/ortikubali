CATATAN PERBAIKAN ORTIBALI

1. Halaman Perpustakaan tetap berupa halaman arsip dokumen resmi dan tidak menggunakan iframe.
2. Halaman Pelayanan Publik tidak lagi menampilkan angka/capaian yang tidak dipastikan berasal dari data sumber yang diminta. Jika data sumber belum tersedia di paket, halaman menampilkan "Data belum tersedia".
3. Musik/audio tidak dimuat atau diputar.
4. Data sumber dan berkas yang sudah ada di paket dipertahankan.

PENTING:
- Paket ini tidak mengarang atau menambahkan data Pelayanan Publik.
- Dokumen/data Pelayanan Publik asli yang belum ada di dalam paket perlu disertakan agar dapat ditampilkan.
- Untuk backend, salin backend/.env.example menjadi backend/.env lalu isi SESSION_SECRET dan password akun awal sendiri. Jangan membagikan file .env.
- Jalankan backend dari folder backend menggunakan: npm install, lalu npm start.
- Buka antarmuka utama melalui server lokal (misalnya Live Server). API backend berjalan di port yang ditentukan pada .env.
