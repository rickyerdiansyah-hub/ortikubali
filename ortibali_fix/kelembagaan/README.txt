ORTIBALI — PORTAL KHUSUS KELEMBAGAAN 2026

CARA MENJALANKAN
1. Ekstrak seluruh isi ZIP ke satu folder.
2. Buka folder ORTIBALI_Kelembagaan_2026 melalui VS Code.
3. Jalankan index.html dengan Live Server.
4. Login menggunakan:
   Username: admin
   Password: ortibali2026

FITUR
- Dashboard ringkasan dan komposisi arsip.
- Daftar perangkat daerah dari 30 arsip Kepgub Peta Jabatan.
- Indeks rekomendasi kelembagaan kabupaten/kota 2024–2026.
- Indeks rekomendasi UPT Pusat.
- Peta Jabatan, Kelas Jabatan, SKJ & Kamus Kompetensi, TPP.
- Perpustakaan dokumen dengan pencarian, filter, buka/unduh.
- Input data tambahan, status, catatan, dan ekspor CSV.

SUMBER DATA
Data awal diindeks dari file yang diberikan:
- ORTIBALI_UPDATE_DATA_KELEMBAGAAN_2026.zip
- 04. Rekomendasi Kelembagaan KabKota 2024-2026.zip

- 09. Pergub dan Kepgub TPP.zip

CATATAN PENTING
- Jumlah arsip yang terindeks pada paket ini: 130 dokumen (PDF/XLS).
- Daftar 30 perangkat/unsur organisasi dibuat dari nama folder/berkas Peta Jabatan; status hanya menyatakan bahwa dokumen peta jabatan tersedia dalam arsip.
- Input tambahan disimpan di localStorage browser/perangkat yang sedang digunakan, bukan database server.
- Login merupakan gerbang demo frontend, bukan autentikasi yang aman untuk produksi.
- Untuk penggunaan resmi multi-pengguna, perlu backend, database, kontrol akses, audit log, dan hosting HTTPS.
- Jangan menghapus folder dokumen atau data.json karena digunakan oleh aplikasi.
