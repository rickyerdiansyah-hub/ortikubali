ORTIBALI FRONTEND - PEMBARUAN MODUL PERPUSTAKAAN

1. Ekstrak seluruh folder ORTIBALI_FRONTEND_LIVE_SERVER.
2. Buka folder tersebut di VS Code.
3. Jalankan index.html dengan Live Server.
4. Klik menu Perpustakaan untuk membuka halaman khusus perpustakaan.
5. Tombol Beranda pada sidebar Perpustakaan kembali ke dashboard utama index.html.

Modul Perpustakaan menggunakan kode dari file Perpustakaan_ORTIBALI_SIDEBAR_LOGIN.zip,
termasuk sidebar khusus, katalog, kategori, login demo tiga tingkat akses, dan 10 PDF sumber.
Animasi masuk halaman dan kartu dibuat ringan agar serasi dengan transisi dashboard ORTIBALI.

Akun demo (hanya frontend/localStorage):
Admin: adminperpus / admin123
Master Admin: master / master123

PENTING: login dan data localStorage bukan keamanan produksi. Backend akan dibuat pada tahap berikutnya.
Jangan gunakan kredensial demo untuk data resmi.
