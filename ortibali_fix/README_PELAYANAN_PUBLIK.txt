MODUL PELAYANAN PUBLIK ORTIBALI

Menu Pelayanan Publik pada dashboard utama sekarang membuka halaman mandiri:
pelayanan-publik/index.html

Jalankan index.html utama melalui Live Server, lalu klik menu Pelayanan Publik.
Tombol Beranda di modul mengarah kembali ke ../index.html.

Tema biru, banner, sidebar, hak akses dan animasi dari paket Pelayanan Publik tetap digunakan; animasi masuk/hover diselaraskan dengan modul Perpustakaan.
Login dan data adalah simulasi frontend berbasis localStorage.
