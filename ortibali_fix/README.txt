PERPUSTAKAAN ORTIBALI - SIDEBAR KHUSUS + LOGIN 3 AKSES

Struktur:
- index.html : website Perpustakaan.
- assets/sidebar-bali.jpg : artwork vertikal yang sudah dipotong agar tidak ada bidang putih.
- assets/banner-perpustakaan.jpg : banner Perpustakaan yang dikirim; tidak ditambah teks HTML.
- dokumen/ : 10 dokumen PDF sumber.

Navigasi sidebar khusus modul:
1. Perpustakaan (ringkasan)
2. Katalog Dokumen
3. Kategori
4. Tambah Dokumen (Admin/Master Admin)
5. Kelola Akun (Master Admin)

Tombol "Beranda" menuju ../index.html (halaman utama ORTIBALI).
Hak akses:
- Publik: tanpa login, dapat melihat dan membuka dokumen.
- Admin: login, tambah, ubah, dan hapus koleksi pada modul Perpustakaan.
- Master Admin: seluruh hak Admin dan dapat membuat/menghapus akun Admin.

Akun DEMO:
- Admin: adminperpus / admin123
- Master Admin: master / master123

PENTING:
Login dan penyimpanan pada paket ini adalah DEMO front-end berbasis localStorage. Jangan gunakan untuk keamanan/produksi karena kredensial dan data dapat diperiksa dari browser dan data hanya tersimpan pada perangkat/browser tersebut. Untuk produksi ORTIBALI, autentikasi, otorisasi, akun, dan database harus dijalankan melalui backend/server. Ganti kredensial demo sebelum demonstrasi.
